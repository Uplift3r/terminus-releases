# Terminus releases

Downloads and update data for [Terminus](https://terminusdeck.com), the truck and coach cab display for Euro Truck Simulator 2 and American Truck Simulator on the Corsair XENEON EDGE.

- **Terminus Setup** (installs the game plugin into ETS2 and ATS): [latest release](https://github.com/Uplift3r/terminus-releases/releases/latest/download/Terminus-Setup.exe)
- `live.json`: the latest widget and plugin versions, read by the widget for its update notice.

The Terminus widget itself is sold on the Elgato Marketplace. Support: support@terminusdeck.com
